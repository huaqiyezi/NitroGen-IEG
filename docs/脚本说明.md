# 脚本说明

> 仓库保留的核心脚本，按功能分目录存放。均用 Python 3.12 运行（详见 [README](../README.md)）。

## 评测主链路（probes/eval/）

| 脚本 | 职责 |
|---|---|
| `run_eval.py` | 评测主脚本：切好的帧 → 推理服务 → 与 parquet 真值比对 → 输出指标表 |
| `plan_test_frames.py` | 生成选帧清单 `test_frames_plan.csv`（IDLE 过滤 + 每组 200 帧；自动读步骤 2 分块） |

## 数据抽取/下载（probes/extract/）

| 脚本 | 职责 |
|---|---|
| `extract_hk_test_chunks.py` | 从 `SHARD_0000.tar.gz` 抽测试分块 parquet + metadata.json |
| `download_shard0.py` | 下载数据集分片 `SHARD_0000.tar.gz`（走代理） |
| `download_videos.py` | 自动读 metadata 下载测试视频（代理自动探测，`--proxy` 可覆盖） |
| `extract_frames.py` | 按选帧清单从视频切帧成 PNG（自动推断视频文件） |

## 统计分析（probes/analysis/）

| 脚本 | 职责 |
|---|---|
| `probe_hk_idle_stats.py` | 统计候选分块的空闲率/活跃度（选块依据） |
| `n2_stats_v4.py` | N2 单游戏标注子集统计与可视化（最终版） |
| `analyze_button_mistakes.py` | 漏按/多按与组合键误配补充分析（输出到 `shards/out/`） |

## 图表与演示（probes/visual/）

| 脚本 | 职责 |
|---|---|
| `make_compare_material.py` | 生成"模型输出 vs 标注"对比表/对比图（输出到 `shards/out/`） |
| `find_compare_cases.py` | 从评测明细中挑选对比案例 |
| `gen_module_diagram.py` | 生成系统模块图（报告用） |
